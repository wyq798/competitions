首先整体上的思路是，构造一个next数组，当字符串匹配有误时，不需要绕主串指针回退，而是利用next数组来实现主串指针不用回退的效果
里面有几个主要的问题：
    1.为什么更新j要用next[j-1]:
        因为对于模式串而言，patt[j]并未被匹配成功，需要放到后面继续匹配，而patt[0:j]这一段才可以替换
    2.在创建next的时候，为什么在prefix_len==0的时候就认定当前字符没有匹配前后缀：
        因为首先patt[prefix_len] != patt[i],说明此时第一个位置就与patt[i]不一样，其次prefix_len==0说明此时没有共同前后缀,所以就没有批匹配字符串了。
